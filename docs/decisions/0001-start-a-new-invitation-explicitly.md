# Start a new invitation explicitly

The host decides when to start a new invitation. Publishing changes to an existing invitation keeps its link and replies, even when the host changes its date, venue, or template. When the host explicitly starts a new invitation, publishing gives it a new link and an empty reply list. The previous invitation stays available with its own replies.

A rescheduled birthday can change the same fields as an invitation for a different occasion. Inferring a new invitation from those changes could break the link guests already have. Reusing the current invitation for every draft could put five birthday replies on a wedding invitation.

The current editor still republishes to the invitation associated with its draft. It has no action to start a separate invitation while keeping the current one.
