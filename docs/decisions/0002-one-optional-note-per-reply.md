# One optional note per reply

A reply has one optional note of up to 300 characters. It has no separate dietary field and no separate message field. The hint under the note names dietary needs and messages as examples.

Guests tell the host different things: an allergy, a late arrival, a song request or a thank-you. A dietary field and a message field would make the guest decide which field each one belongs in, and some fit neither. The host reads each note in full, so separate fields would add nothing the management page uses.

Each extra field is one more control a guest passes on a phone before Send reply.

A dietary field would ask every guest for details about their health, such as allergies. A free note leaves it to the guest whether to share them.

The host cannot filter or total replies by dietary need. A structured field could join the note later without changing it.
